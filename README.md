# Омчанка и Aether · открытая бета

«Омчанка» выпускает ключи Aether и запускает сервер туннеля в одном процессе.
Выпустите ключ на своём VPS, вставьте его в Windows-клиент и проверьте счётчики в панели.

| Возможность | Что доступно в бете |
|---|---|
| Панель | Ключи и пользователи, учёт трафика, отзыв активных соединений |
| Установка | Ubuntu 24.04, HTTPS на IPv4 с автопродлением, отдельный путь входа |
| Управление | Консольное меню, смена портов Aether, домен, журналы и диагностика |
| Windows | Переносимый клиент с импортом ссылок Aether |
| Android | В разработке |

## Установка панели

Для нового VPS с Ubuntu 24.04 и установленным стабильным Rust выполните от root:

```bash
f="$(mktemp)" && curl -fL https://github.com/yrkas1488-ship-it/omchanka-obt/releases/download/v0.1.0-beta.1/install-omchanka-ubuntu.sh -o "$f" && bash "$f"
```

Установщик запросит публичный IPv4, email для Let's Encrypt, порты и данные администратора.
Для проверки Let's Encrypt сервер должен принимать TCP-подключения на порт 80.
После установки сохраните полный HTTPS-адрес. Для управления сервером выполните `omchanka`.

Для существующей установки используйте пункт обновления в меню. Установщик
чистой установки останавливается, если обнаружит существующую конфигурацию.

## Скачать и проверить

Откройте [Releases](https://github.com/yrkas1488-ship-it/omchanka-obt/releases).
В выпуске также есть архив исходников и SHA-256 файлов. В отчётах об ошибках
указывайте версию и шаги воспроизведения. Ссылки Aether и пароли храните отдельно.

Это тестовый выпуск. Полная установка и продление сертификата на чистой Ubuntu
требуют отдельной проверки. Версия сборки панели — **0.1.1.1 (B)**.
