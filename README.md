## Панель одной командой

На Ubuntu / Debian выполните от root:

```bash
bash <(curl -fsSL https://github.com/yrkas1488-ship-it/omchanka-obt/releases/download/v0.1.1.2/install-omchanka-ubuntu.sh)
```

На новом сервере установщик подготовит зависимости и запросит параметры панели.
На стандартной установке `/opt/omchanka` он собирает обновление, сохраняет прежний
бинарник и откатывает его при неудачном запуске. Ключи, сертификаты и настройки
сохраняются. Сборка занимает несколько минут; перезапуск прерывает соединения Aether.

## Что добавлено

**0.1.1.2:** после трёх неудачных проверок клиенты действительно перезапускают живое ядро, с ограничением раз в минуту. Android сохраняет TUN, Windows — включённый kill switch. Ручное отключение отменяет повторы. Клиент и обновлённая панель пишут счётчики TLS без содержимого пакетов; для серверной диагностики отдельно обновите VPS. Это не доказанное устранение первопричины сетевых таймаутов.

Установщик проверяет наличие 2 ГиБ в /tmp перед сборкой.


**0.1.1.1:** скриншоты Android блокируются только при вводе ключа или наличии ссылки в поле. После сохранения или очистки поля снимки разрешаются.


Android получил значок Aether с поддержкой круглых и тематических иконок.
Windows и Android используют единый номер **0.1.1.2**.


- **Серверы в клиентах:** до 32 сохранённых ключей, выбор, проверка TCP/TLS/доступа,
  последняя задержка, удаление из списка. Android Keystore и Windows DPAPI защищают
  сохранённые ссылки. Старый ключ доступен после обновления.
- **QR-код в Омчанке:** у каждого созданного ключа. Android сканирует камерой локально;
  очень длинную ссылку можно скопировать вручную. QR содержит пароль доступа.
- **Android — приложения напрямую:** выбор приложений с иконкой запуска, исключённых
  из VPN. Применяется после переподключения. Системная блокировка без VPN может
  запрещать доступ исключённым приложениям.
- **Омчанка 0.1.1.2 (B):** срок в днях и суммарная квота трафика при создании ключа.
  Старые ключи остаются без ограничений. После перезапуска сервера до 1 МиБ
  неиспользованного резерва квоты на ключ может считаться потраченным.
- **Обновления из клиентов:** версия и список изменений; по подтверждению открывается
  скачивание APK/ZIP. Установка выполняется пользователем, без тихой замены файлов.
- **Состояние связи:** проверка Aether-сервера каждые 30 секунд, после двух ошибок —
  «Связь потеряна», повторы с паузами до 60 секунд. Отключение отменяет повторы.
  Android сохраняет TUN при перезапуске ядра; Windows сохраняет включённый kill switch.

## Начать пользоваться

Android: установите APK поверх текущего приложения. Windows: распакуйте ZIP,
запустите `Aether.exe` и импортируйте свой ключ. Ссылки Aether и QR храните как пароль.
Для использования QR и лимитов сначала обновите панель на VPS.

## Проверки и ограничения

Прошли 28 тестов ядра, тест панели, 5 интеграционных сценариев с реальными
локальными бинарниками, проверка зашифрованного списка серверов Windows,
декодирование плотного QR, сборки клиентов и проверка подписи APK.
Проверены отказ истёкшему ключу и запрет передачи данных сверх квоты.
Камера, Android Keystore и исключения приложений на физическом телефоне ещё
требуют проверки. Отдельные TCP/TLS-таймауты исследуются; независимого аудита
безопасности не было. Доступность сервера не гарантирует доступность каждого сайта.
